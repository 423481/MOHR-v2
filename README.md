# بسته انتشار MOHR v2.2 — مسیریابی متمرکز، ۱۵ فایل

این بسته بر پایه نسخه مستقل `MOHR-v2.1-reliability-merge` ساخته شده است. فایل‌های اصلی و بسته‌های قبلی تغییر نکرده‌اند.

## ساختار
- `index.html`: پوسته و بارگذار اصلی؛ همه مسیرهای صفحه از طریق پارامتر `page` باز می‌شوند.
- `mohr-part-01` تا `mohr-part-10`: ده بخش منطقی برنامه؛ جدا و با ترتیب اجرای اصلی حفظ شده‌اند.
- `shared.html`: مانیفست و پیکربندی صفحه‌ها.
- `actions.html`: فایل کمکی حفظ‌شده از بسته مبنا.
- `sw.js`: فایل Service Worker موجود در بسته مبنا؛ رفتار آن در این مرحله بازطراحی نشده است.

## نشانی صفحه‌ها
به‌جای فایل‌های جداگانه، صفحه‌ها از این الگو استفاده می‌کنند:
`index.html?page=dashboard.html`

مقدار `page` باید یکی از کلیدهای تعریف‌شده در `shared.html` و بخش `mohr-manifest.pages` باشد. پارامترهای دیگر نشانی، از جمله `demo=1`، حفظ می‌شوند.

## نکات انتشار و محدودیت‌ها
- ده بخش اصلی حذف یا با هم ادغام نشده‌اند.
- کدهای اجرایی داخل ده بخش، به‌جز تغییر مسیریابی در بخش `core/pages`، بازنویسی نشده‌اند.
- کلیدها و ساختار داده‌های ذخیره‌شده تغییر داده نشده‌اند.
- این بسته به‌صورت ایستا بررسی شده است؛ آزمون مرورگر واقعی، چندکاربره، Supabase/RLS و سناریوهای قطع و وصل شبکه در این مرحله اجرا نشده‌اند.
- Service Worker موجود در برنامه اصلی هنگام راه‌اندازی ممکن است ثبت قدیمی خود را لغو کند؛ بنابراین این بسته را نباید بدون آزمون آفلاین واقعی، دارای تضمین آفلاین کامل تلقی کرد.
- برای اجرا از GitHub Pages یا وب‌سرور ایستا استفاده کنید؛ بازکردن مستقیم با `file://` ممکن است به‌دلیل `fetch` فایل‌های بخش‌ها کار نکند.

## تغییر مهم سازگاری
نشانی‌های قدیمی مانند `dashboard.html` به فایل فیزیکی جداگانه نیاز ندارند؛ معادل جدید آن‌ها `index.html?page=dashboard.html` است. لینک‌های بیرونی یا نشانک‌های قدیمی باید به نشانی جدید منتقل شوند.
